# Variable Active Filter

An adjustable active audio filter designed and simulated using LTspice.

The circuit can operate as both a high-pass and low-pass filter, with an adjustable cutoff frequency.

## Project

- Analog audio filter
- Active filter
- Adjustable cutoff frequency
- NE5532 op-amp
- LTspice simulation
- ±9 V supply
