# LTspice Simulation

This directory contains the LTspice simulation of the Variable Active Filter.

## Files

* `ActiveFilter_LTspice.asc` — LTspice schematic and simulation file.
* `ActiveFilter_falstad.txt` — falstad schematic and simulation file. 

## Purpose

The simulation is used to verify the filter's behavior and frequency response, including the effect of the adjustable cutoff frequency.

The simulated results are compared with the expected theoretical behavior of the circuit.
